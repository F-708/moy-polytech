# Мой Политех

Приложение расписания Минского политехнического колледжа для Android.
Работает без сервера: само скачивает расписание с сайта колледжа, разбирает его
и хранит на устройстве.

## Возможности

- Расписание своей группы на сегодня, завтра и по календарю; расписание любой группы и кабинета.
- Домашние задания, оценки, материалы (PDF, DOCX, изображения) с собственными просмотрщиками.
- Карта колледжа с маршрутами между кабинетами.
- Виджеты: «до звонка», «сейчас и дальше», «расписание на сегодня», «звонки».
- Строка отсчёта до конца урока в уведомлениях.
- Каталог преподавателей, тёмная тема, компактный режим расписания.
- Режим преподавателя: своё расписание с группами вместо ФИО.
- Автоматическая проверка обновлений через Releases этого репозитория.

## Установка

Готовые APK — во вкладке [Releases](../../releases/latest).
Файл `moy-polytech-<версия>.apk` — основная сборка.

## Сборка

Требования: JDK 21, Android SDK (compileSdk 36).

```bash
./gradlew :app:testStandardDebugUnitTest   # тесты
./gradlew :app:assembleStandardRelease     # релизный APK
```

Релизная подпись берётся из `keystore.properties` или переменных окружения
`KEYSTORE_PATH`, `STORE_PASSWORD`, `KEY_PASSWORD`. Без ключа сборка подписывается
отладочным ключом и предупреждает об этом.

## Обновления

Приложение раз в 12 часов проверяет последний Release, скачивает APK,
проверяет пакет и подпись, затем предлагает установку.

## Контент-пакет: справочники и фото

Справочники (`teachers.csv`, `group_codes.csv`, `college_map.json`) и фото
преподавателей (`content/teachers_photos/`) доставляются приложению пакетом
`content/content-pack.zip` с манифестом `content/version.json`. Оба процесса
автоматизированы GitHub Actions:

- **Фото**: положите новое или заменённое фото в `content/teachers_photos/`
  и запушьте в `main` — сжатие автоматическое. Можно пушить исходники хоть
  4000px с телефона: workflow сам сожмёт их до стандарта приложения
  (длинная сторона ≤512 px, JPEG q80, 4:2:0, без EXIF), а затем пересоберёт
  пакет. Имя файла менять нельзя (на него ссылается `teachers.csv`),
  расширение сохраняется как есть. Повторная обработка уже сжатых фото
  не выполняется (порог: ≤512 px и ≤200 КБ), так что процесс идемпотентен.
- **Справочники**: изменение CSV/JSON в `content/` просто пересобирает пакет.

Если содержимое `content/` фактически не изменилось, пакет не пересобирается
и `version.json` не растёт.
